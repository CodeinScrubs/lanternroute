# Code of Conduct

## Our standard

LanternRoute is a technical project maintained by people with different
backgrounds and experience levels. We expect everyone to be constructive,
patient, and respectful in issues, pull requests, reviews, and discussions.

Unacceptable behavior includes harassment, personal attacks, discrimination,
deliberate disruption, publishing private information, and any conduct that
would make a reasonable contributor feel unsafe or unwelcome.

## Maintainer response

Maintainers may edit, close, or remove comments and contributions that violate
this standard. Repeated or serious violations may result in a temporary or
permanent ban from project spaces.

## Reporting

Report conduct concerns privately to the repository maintainers through the
GitHub contact options. Do not include sensitive proxy credentials or private
network details in a report.
