# Security Policy

## Supported versions

Only the latest release and the default branch are supported. This project is
Windows-only and requires Administrator privileges for TUN route management.

## Reporting a vulnerability

Please do not open a public issue for an undisclosed vulnerability. Use the
private security advisory workflow on GitHub, or contact the repository owner
privately with:

- affected release or commit
- Windows version and architecture
- exact reproduction steps
- logs with proxy credentials and private addresses removed
- a suggested severity and impact assessment

Do not include SOCKS credentials, subscription URLs, tokens, or private keys in
reports. We will acknowledge a report when received and publish a fix or
mitigation when practical.
